佳安智能传送带抓取说明文档
一、基本介绍
传送带抓取是指机器人动态抓取传送带上的物料。抓取系统需配
有相机，当传送带载着物料运动时，相机拍照并识别物料，然后将物
料点位信息发送给控制系统，控制系统控制机器人去追踪物料，追到
之后可以完成一定的动作（相对物料上某个位置完成相对运动），之
后抓取物料到放料点。佳安控制器目前可以支持一条传送带（传送带
类型可以是直线传送带，也可以是圆形传送带），多种物料，以及多
种机型。用户可以使用 Scara,Delta 以及 Puma 构型的机器人完成抓取
任务。
二、传送带配置
在实现抓取任务之前，需要进行抓取参数的配置，具体如下：
1. 工具坐标系标定
对于 Puma6 轴机器人使用四点法标定工具坐标系，对于 Delta 和
Scara 机器人可以根据用户需要决定是否需要标定工具坐标系（delta
和 scara 工具一般与法兰共线，不需要标定）。
2. 标定工件坐标系
工件坐标系的标定在直线传送带和圆形传送带下是不同的，下面
分别介绍：
1) 直线传送带
工件坐标系需要使用三点法进行标定。工件坐标系的 X 方向需要
与传送带前进方向一致，如图 1 所示，标定时可以在传送带上放置一
个标记物，让 TCP 点与标记物重合，确定第一个标定点；然后让传送
带向前移动一段距离，在将工具 TCP 移动到标记物，以此确定第二个
标定点；按照右手定则以及 Z 的向上的原则确定 Y 轴方向，并确定第
三个标定点。
图 1 工件坐标系标定
2) 圆形传送带
圆形传送带的工件坐标系需设定在传送带转动的圆心处，使用三
点法标定圆心，具体步骤如下。如图 2 所示，标定时可以在传送带上
放置一标记物，让机器人 TCP 与之重合，示教第一个点；然后转动传
送带，再次让 TCP 与标记点重合，示教第二个点；第三点确定与第二
点相同。示教点位之后选择要标定的坐标系的号，点击标定按钮。
图 2 圆心标定
圆心标定界面如下图所示，选择传送带为旋转类型，点击标定按钮。
3. 脉冲当量标定
脉冲当量是指传送带走过一定距离，控制系统应该下发多少脉冲
的转换关系。主要目的是使传送带移动的距离的单位与机器人末端保
持一致。具体步骤如下：
1）在传送带上方一标记物，让工具 TCP 点与之重合
2）点击脉冲当量标定按钮
3）示教第一个点
4）控制传送带移动一段距离
5）移动工具 TCP 到标记物处，示教第二个点
6）点击标定按钮计算标定结果
7）校验标定结果，记录当前传送带位置，将传送带移动一段距离，
距离此时传送带位置，判断两次位置之差与实际移动的距离是否一致，
若一致说明标定准确，否则需要重新标定。
备注：设置目标速度为固定值时，标定值越大，实际运行速度越慢，
有可能观察不到传送带的实际移动，可以增大目标速度观察是否在运
动。同时校验标定结果是否正确。
4. 通讯设置
通信设置主要是确定相机与传送带直接的通信方式以及拍照的触
发方式。通信方式支持 modbus 和 socketTCP，推荐使用 socketTCP 方
式，控制器可以作为客户端，也可以作为服务器。
相机拍照触发方式支持时间触发，距离触发以及 IO 上升沿输入触
发
5. 抓取参数设置
抓取过程中需要设定抓取区域，机器人只会抓取区域中的物体，
如果未进入区域则等待，超出区域则丢弃，如果在抓取过程中物料超
出抓取区域则立刻返回待机点。抓取区域必须在既定的工具工件坐标
系下设定，正负限位需要与工件坐标系一致，如图 2 所示。

三、相机标定
1）连接相机
佳安视觉服务器 ip 地址可以有用户设置，端口号默认为 9527。配
置相机通信参数后，创建工程，编程（编程查看后续例程）初始化网
络，观察到通信连接之后可以开始标定。如图 3 所示为网络是否连接
状态标记，灰色表示连接失败，绿色表示连接成功。
图 3 网络状态显示
备注：如网络连接失败按照如下策略查找原因
1）查看网线硬件连接是否正确，网口是否使用正确，是否有松动；
2）打开终端，执行 ifconfig 指令，确认相机端和控制器端的 IP 地址是否配置正确；
3）确认网络是否能够 ping 通 执行指令：ping xxx.xxx.xxx.xxx(对方 ip)；
4）检查相机端程序是否运行；
5）检查控制器端是否初始化网络；
2）标定板拍照
将标定板放到相机正下方，点击拍照
3）9 点标定
移动机器人工具 TCP 点依次到标定板 9 个点的位置，并示教，如
果相机距离机器人较远，可以移动传送带一段距离，并记录移动的长
度，计算标定结果是输入移动距离。
四、指令介绍
指令 功能
initNet 初始化网络，开始触发拍照和接受数据
startTrigPhoto 开始触发拍照
stopTrigPhoto 停止触发拍照
cameraIsConnected 获取相机网络连接状态
getGrabQeueData 获取抓取数据
delteGrabQeueData 删除指定队列的抓取数据
clearGrabQeueData 清空指定传送带和队列的数据
addToMissDataQueue 移除点位并添加到丢失队列
con_fast_catch 传送带快速抓取指令
1. InitNet(camera_id)
指令说明：初始化网络，开始网络连接，并循环判断相机端是否返回物料点
位；
参数说明：camera_id:相机号，用于有多个相机的情形，默认为 1
2. startTrigPhoto(camera_id)
指令说明：开始触发拍照，按照设定的触发方式进行拍照触发
参数说明：camera_id:相机号，用于有多个相机的情形，默认为 1
3. stopTrigPhoto(camera_id)
指令说明：停止触发拍照
参数说明：camera_id:相机号，用于有多个相机的情形，默认为 1
4. cameraIsConnected(camera_id)
指令说明：获取相机网络连接状态
参数说明：camera_id:相机号，用于有多个相机的情形，默认为 1
5. GrabData = getGrabQeueData(con_id,queue_id)
指令说明：获取当前物料信息
参数说明：con_id:传送带号，用于有多条传送带的情形，默认为 1
queue_id:队列号，用于一条传送带有多种物料的情形，默认为 1
返回值：GrabData：当前物料信息
6. delteGrabQeueData(queue_id)
指令说明：删除指定队列的抓取数据
参数说明：queue_id:队列号，用于一条传送带有多种物料的情形，默认为 1
7. clearGrabQeueData(queue_id)
指令说明：清空指定队列的抓取数据,同时清空丢失队列
参数说明：queue_id:队列号，用于一条传送带有多种物料的情形，默认为 1
8. addToMissDataQueue(queue_id)
指令说明：移除点位并添加到丢失队列
参数说明：queue_id:队列号，用于一条传送带有多种物料的情形，默认为 1
9. con_fast_catch
指令说明：传送带快速抓取指令，抓取分三个阶段（追踪-抓取-返回放料点）
参数说明：obj_pe:物料位姿，x,y 由相机拍照获得，z 有用户设置
end_pe:放料点位姿
vel:抓取速度
con_id:传送带号,决定抓取那条传送带上的物料
queue_id：队列号，决定抓取那个队列上的物料点
con_pos：要抓取的点在拍照时传送带的位置，由相机获得
catch_height：抓取阶段最低绝对限位高度
sync_time：同步运动时间，追到物料后等待一定时间在开始抓取
do_index：io 触发索引，在抓取过程中，向下抓取到物料之后，
触发 io 输出
do_value：io 触发值
五、编程实例
变量说明：
(1) end_p:放料点 变量类型：RobotTarget
(2) obj_p:物料目标点 变量类型：RobotTarget
(3) ch:抓取最低绝对限位高度,不能低于传送带所在平面高度，以防撞机 变量类型：
double
(4) grab_data：抓取队列中第一个物料的抓取信息 变量类型：GrabData
(5) con_pos：队列中第一个物料在拍照时传送带的位置 变量类型：double
initNet(1) // 初始化网络，开始网络连接
ch=-5 // 最低抓取绝对限位高度
clearGrabQeueData(1,1) // 清空抓取队列数据
startTrigPhoto(1) // 开始触发拍照
WHILE true DO // 循环抓取
WHILE true DO
Sleep <200>
grab_data=getGrabQeueData(1,1) // 获取抓取队列中第一个物料的信
息以及数据
IF grab_data.state==0 THEN // 状态为 0，可以抓取，跳出循环进行抓取
BREAK
ELIF grab_data.state==-1 THEN // 状态为-1，物料已出抓取区域，放弃
该物料添加到丢失队列
addToMissDataQeue(1)
END_IF
END_WHILE
obj_p.x=grab_data.x // 获取物料 x 方向位置
obj_p.y=grab_data.y // 获取物料 y 方向位置
obj_p.z=15 // 目标点在工件坐标系下的绝对位置高度，设置值不
能低于最低抓取绝对限位高度
con_pos=grab_data.con_pos // 获取拍照时传送带的位置
ConFastCatch <obj_p,end_p,v1000,1,1,con_pos,ch,0,15,true> // 抓取物料
delteGrabQeueData(1) // 删除抓到的物料
END_WHILE // 循环开始抓取队列中下一个物料
stopTrigPhoto(1) // 停止触发拍照
六、注意事项
1. 9 点标定时开启网络但不要开启拍照触发
2. 9 点标定的点位和抓取区域设置的范围都是在工件坐标系下的描述
