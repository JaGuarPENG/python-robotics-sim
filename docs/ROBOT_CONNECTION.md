## 通信协议详解

### 1. 网络配置

| 设备 | IP 地址 | 说明 |
|------|---------|------|
| 工控机 | `192.168.0.5` | 机器人控制器 |
| 你的电脑 | `192.168.0.x` | 需要在同一网段 |

**网络设置**：确保你的电脑网卡 IP 设置为 `192.168.0.x`（如 `192.168.0.100`）

### 2. 双端口架构

系统使用**双端口并发**设计，分离监控和控制功能：

| 端口 | 用途 | 特点 |
|------|------|------|
| **5888** | 监控端口 | 只读，高频查询（50Hz），超时短（3秒） |
| **5999** | 控制端口 | 读写，发送运动指令，超时长（60秒） |

**为什么要分开？**
- 控制指令（如 MoveJ）会阻塞等待机器人动作完成
- 如果只用一个端口，发送运动指令时无法同时读取状态
- 分开后，监控线程可以持续刷新，控制线程独立等待

### 3. 通信协议

使用 **WebSocket** 协议，数据格式为二进制：

```
┌──────────────────────────────────────────────────────────┐
│                    数据包结构                             │
├──────────────┬───────────────────────────────────────────┤
│   Header     │   Payload (JSON 字符串)                   │
│   40 字节    │   变长                                    │
├──────────────┼───────────────────────────────────────────┤
│  msg_len(4)  │  {"cmd": "get", ...}                     │
│  type(4)     │                                          │
│  magic(8)    │                                          │
│  reserved(24)│                                          │
└──────────────┴───────────────────────────────────────────┘
```

## 数据流向

### 监控数据流（5888 端口）

```
Python 程序                    工控机
    │                            │
    │  ──── "get" 命令 ────►     │
    │                            │
    │  ◄─── 状态 JSON ─────      │
    │                            │
    ▼                            │
解析 motor_pos                   │
    │                            │
    ▼                            │
更新 3D 显示                     │
```

**返回数据示例**：
```json
{
  "ret_context": {
    "motion_msg": {
      "motor_pos": [[0, -90, 90, 0, 90, 0]]  // 6个关节角度（度）
    }
  }
}
```

### 控制数据流（5999 端口）

```
Python 程序                    工控机                    机器人
    │                            │                         │
    │  ── login 命令 ──►         │                         │
    │  ◄── 登录成功 ───          │                         │
    │                            │                         │
    │  ── manual_en ──►          │                         │
    │  ◄── 使能成功 ───          │  ── 使能电机 ──►        │
    │                            │                         │
    │  ── movej 命令 ──►         │                         │
    │      (阻塞等待)            │  ── 运动指令 ──►        │
    │                            │                         │
    │                            │  ◄── 运动完成 ───       │
    │  ◄── 执行完成 ───          │                         │
```

## 线程架构

```
┌─────────────────────────────────────────────────────────────┐
│                        主线程                                │
│                    (3D 界面 + 键盘监听)                       │
│                           │                                  │
│              ┌────────────┼────────────┐                    │
│              ▼            │            ▼                    │
│     ┌─────────────┐       │    ┌─────────────┐              │
│     │  监控线程    │       │    │  控制线程    │              │
│     │  (daemon)   │       │    │  (daemon)   │              │
│     │             │       │    │             │              │
│     │ Port: 5888  │       │    │ Port: 5999  │              │
│     │ 50Hz 循环   │       │    │ 等待队列    │              │
│     └──────┬──────┘       │    └──────┬──────┘              │
│            │              │           │                     │
│            ▼              │           ▼                     │
│     shared_data      cmd_queue    cmd_queue                 │
│     (关节角度)       (运动指令)                              │
└─────────────────────────────────────────────────────────────┘
```

### 数据共享

| 变量 | 类型 | 用途 |
|------|------|------|
| `shared_data["joints"]` | list | 当前关节角度（监控线程写，主线程读） |
| `shared_data["running"]` | bool | 运行标志（控制程序退出） |
| `cmd_queue` | Queue | 运动指令队列（主线程写，控制线程读） |
| `data_lock` | Lock | 保护 shared_data 的线程锁 |

## 示教器程序的角色

示教器程序是**独立的客户端**，与你的 Python 程序**并行连接**到工控机：

```
┌──────────────┐     ┌──────────────┐
│  Python 程序  │     │  示教器程序   │
│  (你的电脑)   │     │  (你的电脑)   │
└──────┬───────┘     └──────┬───────┘
       │                    │
       │   WebSocket        │   WebSocket (或其他协议)
       │                    │
       └────────┬───────────┘
                │
                ▼
        ┌──────────────┐
        │    工控机     │
        │  192.168.0.5 │
        └──────────────┘
```

**注意事项**：
- 两个程序可以同时连接工控机
- 但**不要同时发送控制指令**，可能产生冲突
- 建议：用示教器手动操作时，关闭 Python 程序的控制功能

## 常用指令

| 指令 | 端口 | 说明 |
|------|------|------|
| `login` | 5888/5999 | 登录认证 |
| `get` | 5888 | 获取机器人状态 |
| `manual_en` | 5999 | 使能机器人 |
| `manual_mvaj` | 5999 | 关节运动 (MoveJ) |
| `set_jog_vel` | 5999 | 设置 JOG 速度 |
| `set_pgm_vel` | 5999 | 设置程序速度 |

## 快速检查清单

### 连接前检查

- [ ] 网线已连接电脑和工控机
- [ ] 电脑 IP 设置为 `192.168.0.x`（与工控机同网段）
- [ ] 工控机已开机，控制系统已启动
- [ ] 能 ping 通工控机：`ping 192.168.0.5`

### 运行时检查

- [ ] 5888 端口可连接（监控）
- [ ] 5999 端口可连接（控制）
- [ ] 登录成功（用户名/密码正确）
- [ ] 机器人已使能（manual_en）

### 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 连接失败 | IP 不在同一网段 | 检查电脑 IP 设置 |
| 5999 连接失败 | 控制服务未启动 | 在示教器中启动控制服务 |
| 运动指令无响应 | 机器人未使能 | 先调用 `manual_en` |
| 超时 | 动作时间过长 | 增加 timeout 参数 |
