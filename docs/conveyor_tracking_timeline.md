## 三、延迟构成详细分析

### 总延迟公式

```
总预判延迟 = (loop_interval × look_ahead_frames) + system_latency_offset
          = (16.67ms × 3) + 150ms
          = 50ms + 150ms
          = 200ms
```

### 延迟分量拆解

| 延迟源 | 估算值 | 占比 | 说明 |
|--------|--------|------|------|
| **控制周期** | 16.67ms | 8% | 60Hz主循环周期 |
| **预测缓冲** | 33.33ms | 17% | look_ahead_frames=3帧平滑 |
| **通信延迟** | 5-10ms | 3% | WebSocket发送+ACK |
| **控制器处理** | 10-20ms | 6% | 机器人控制器解析指令 |
| **伺服响应** | 50-100ms | 30% | 伺服电机开始动作 |
| **机械惯量** | 30-50ms | 15% | 机械臂质量带来的延迟 |
| **视觉处理** | 16-33ms | 8% | PyVista渲染+FOV检测 |
| **IK解算** | 0.7-1.7ms | <1% | FastIK计算 (日志中可见) |
| **系统裕量** | 20-30ms | 12% | 其他未建模延迟 |

## 四、关键问题总结

### 问题 1: HOVERING 阶段初始误差过大

```
现象: XY误差从 190mm 开始逐渐收敛
根因: 200ms前馈预判 vs 机械臂实际响应滞后
     机械臂从静止/远处启动需要 100-200ms 才能有效响应
影响: 增加 HOVERING 阶段持续时间 (~300ms)
```

### 问题 2: 盲抓阶段(APPROACHING)的累积误差

```
现象: 触碰时Y方向仍有 2-3mm 残余误差
根因: locked_y 基于匀速假设，但实际可能: 
     - 传送带速度波动
     - 机械臂Y轴跟踪存在静差
     - 前馈系数不准导致预判偏差
影响: 直接影响最终触碰精度
```

### 问题 3: Z轴触碰判定阈值

```
现象: 视觉表面高度 0.211m，判定阈值 0.265m，差距 54mm
根因: tool_touch_offset 是经验值，未考虑:
     - 探针实际压缩量
     - 小球表面材质弹性
     - 机械臂Z轴绝对定位精度
影响: 可能过早/过晚触发触碰判定
```

## 五、优化方向建议

### 方案 A: 可变前馈权重 (针对问题1)

```python
# 大误差时减少前馈权重，避免过度预判
if real_xy_distance > 0.05:  # >5cm
    feedforward_gain = 0.3   # 30%前馈
else:
    feedforward_gain = 1.0   # 100%前馈

predicted_y = target_pos[1] + (speed * latency * feedforward_gain)
```

### 方案 B: 盲抓间歇修正 (针对问题2)

```python
# APPROACHING阶段每N帧检查一次实际位置
if self.frame_count % 10 == 0:  # 每10帧(167ms)
    actual_y = tcp_m[1]
    drift = actual_y - self.locked_y
    if abs(drift) > 0.001:  # 漂移>1mm
        self.locked_y += drift * 0.5  # 修正50%
```

### 方案 C: 联合速度判定 (针对问题3)

```python
# 结合Z轴位置+速度判定触碰
z_velocity = (current_z - last_z) / dt
if actual_tip_z <= touch_threshold and z_velocity < threshold:
    # 位置到达阈值且速度骤降(接触到物体)
    trigger_touch()
```
