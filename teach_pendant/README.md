# 机器人示教器用户手册 (Teach Pendant User Manual)

本手册详细介绍了 Python 机器人示教器软件的安装、配置与各项功能使用方法。该软件用于控制 UR5 构型机器人，支持实时状态监控、关节调试、3D 可视化及视觉伺服轨迹执行。

## 1. 快速开始

### 1.1 环境要求
- Windows 10/11
- Python 3.8+
- 依赖库：`PyQt5`, `numpy`, `matplotlib`, `roboticstoolbox-python`, `spatialmath-python`, `pyvista`, `vtk`

### 1.2 启动软件
在项目根目录下，打开终端运行以下命令：

```bash
# 方式 A: 直接运行脚本
python teach_pendant.py

# 方式 B: 作为模块运行 (推荐)
python -m teach_pendant
```

## 2. 界面功能详解

软件界面分为左右两大部分：
- **左侧**：3D 实时监控与状态显示
- **右侧**：功能控制面板 (选项卡式布局)

### 2.1 连接控制 (Connection Panel)
位于右侧 "基础控制" 选项卡顶部。

| 控件 | 说明 |
|------|------|
| **IP** | 输入机器人的 IP 地址 (默认为 `192.168.0.10`)。 |
| **连接** | 建立 WebSocket 连接 (端口 5999)。连接成功后指示灯变绿。 |
| **登录** | 以操作员身份登录控制器。 |
| **使能** | 激活机器人伺服系统。**注意**：所有运动指令都需要机器人处于“使能”状态。 |
| **退出登录** | 断开权限，禁用控制功能。 |

**状态指示灯**：
- **WS**: WebSocket 连接状态 (红/绿)
- **登录**: 用户登录状态
- **使能**: 伺服系统状态
- **跟随**: 跟随模式开启状态

### 2.2 机器人状态面板 (Robot Status Panel)
位于左侧下方，实时显示核心数据。

- **末端位姿 (TCP)**: 显示工具末端中心点在基座坐标系下的位置 (X, Y, Z) 和姿态 (Rx, Ry, Rz)。
  - 若显示 `*` 号，表示该值为基于关节角度的正运动学计算值 (模型值)。
  - 若无 `*` 号，表示该值为控制器返回的真实反馈值。
- **系统状态**: 显示运行状态 (Running/Stopped)、激活状态 (Enabled/Disabled) 及任何报警信息。
- **线性偏差**: 在轨迹执行过程中，实时显示目标点与实际 TCP 的欧氏距离误差。

### 2.3 关节控制面板 (Joint Control Panel)
位于右侧 "基础控制" 选项卡。

- **关节角度**: 实时显示 J1 - J6 六个关节的角度值。
- **手动点动 (Jog)**:
  - **步进选择**: `1.0°` (微调), `5.0°` (正常), `10.0°` (快速)。
  - **+/- 按钮**: 点击对应关节的按钮，机器人将向正/负方向运动指定步长。
- **快速定位 (Presets)**: 预设的常用姿态 (如“零位”、“拍照位”)，点击后机器人会自动规划路径并移动。

### 2.4 3D 机械臂监控 (3D View)
位于左侧上方。

- **实时同步**: 画面中的 3D 模型会实时跟随实体机器人的动作。
- **轨迹预览**: 加载视觉轨迹后，会显示绿色的路径点连线。
- **实际轨迹**: 执行运动时，会实时绘制红色的实际运动路径。
- **操作**:
  - **旋转**: 鼠标左键拖拽
  - **平移**: Shift + 左键拖拽
  - **缩放**: 鼠标滚轮

### 2.5 视觉引导面板 (Vision Panel)
位于右侧 "视觉引导" 选项卡，用于处理视觉伺服任务。

1. **轨迹源文件**: 点击 "浏览" 选择 `.csv` 轨迹文件 (格式: `x,y,z,rx,ry,rz` 或 `x,y,z`)。
2. **加载预览**: 读取文件并在 3D 视图中生成绿色预览线。
3. **执行控制**:
   - **普通执行**: 通过 WebSocket 发送关节运动指令 (适用于离线轨迹)。
   - **UDP 高速执行**: 启动自动化流水线 (自动对位 -> 切换跟随模式 -> UDP 增量下发)。**推荐用于动态视觉伺服**。
4. **频率设置**: 可调整轨迹点的执行频率 (Hz)，默认 30Hz。
5. **导出**: 执行完成后，可点击 "导出实际轨迹" 将记录的真实路径保存为 CSV 文件用于分析。

### 2.6 跟随模式与遥操作 (Follower & Teleop)
位于右侧 "高级运动" 选项卡。

- **跟随模式控制**:
  - **一键启动跟随模式**: 自动执行 `start_follower` -> `set_jog_coordinate` -> `follower_cart` 序列。
  - **手动指令**: 单步执行上述指令用于调试。
- **遥操作测试**:
  - **连接 UDP**: 连接到控制器 UDP 端口 (9998)。
  - **步进测试**: 发送 X/Y/Z 方向的微小增量，测试 UDP 通信延迟与方向正确性。

## 3. 典型操作流程

### 场景 A：手动调试机器人姿态
1. 启动软件。
2. 输入 IP，点击 **连接** -> **登录** -> **使能**。
3. 切换到 "基础控制" 选项卡。
4. 选择步进量 (如 5.0°)。
5. 使用 J1-J6 的 +/- 按钮调整姿态。
6. 观察左侧 3D 视图确认动作。

### 场景 B：执行视觉生成的轨迹 (UDP 模式)
1. 确保视觉算法已生成轨迹文件 (如 `csv/vision_trajectory.csv`)。
2. 在示教器中连接并使能机器人。
3. 切换到 **"视觉引导"** 选项卡。
4. 点击 **"浏览"** 选择该 CSV 文件。
5. 点击 **"加载预览"**，确认 3D 视图中轨迹合理。
6. 点击 **"执行轨迹 (UDP流水线)"**。
7. 系统将自动：
   - 移动机器人到轨迹起点。
   - 开启跟随模式。
   - 高速下发轨迹点。
8. 执行完毕后，点击 **"导出实际轨迹"** 保存数据。

## 4. 常见问题 (FAQ)

**Q: 点击“连接”后状态灯一直是红色？**
A: 检查 IP 地址是否正确，Ping 机器人 IP 确认网络通畅。检查控制器端 WebSocket 服务是否开启 (端口 5999)。

**Q: 3D 视图中的机器人不动？**
A: 确认“连接”状态灯为绿色。如果连接正常，尝试点击“手动刷新状态”按钮。

**Q: UDP 轨迹执行时报错 "对位失败"？**
A: 轨迹起点的逆运动学 (IK) 解算失败。可能是起点超出了机器人工作空间，或与当前姿态差异过大导致多解冲突。请尝试手动将机器人移动到起点附近。

**Q: 轨迹执行非常卡顿？**
A: 检查“视觉引导”面板中的频率设置。如果设得太高 (如 >100Hz) 且网络延迟较大，可能会导致阻塞。建议设为 30-50Hz。

**Q: 如何保存机器人当前的实际位姿？**
A: 目前可以使用“导出实际轨迹”功能保存运动过程中的所有点。单点记录功能将在后续版本添加。
