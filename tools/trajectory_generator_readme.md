# 两点直线轨迹生成器 使用说明

## 功能介绍

在 KAANH_Digital_Twin 仿真平台中新增了【轨迹生成】标签页，可以通过确认起点和终点，自动生成直线插补轨迹并导出CSV文件。

## 使用方法

### 1. 启动程序
```bash
python KAANH_Digital_Twin_launcher.py
```

### 2. 切换到"轨迹生成"标签页

### 3. 设置起点和终点

#### 方式一：手动输入坐标
- 在起点和终点的输入框中直接输入坐标值
- 格式：X(mm), Y(mm), Z(mm), Rx(°), Ry(°), Rz(°)

#### 方式二：使用当前机器人位置（推荐）
1. 在"基础控制"标签页连接机器人并使能
2. 使用Jog模式将机器人移动到起点位置
3. 回到"轨迹生成"标签页，点击【📍 设为当前位置】设置起点
4. 重复步骤2-3设置终点

### 4. 配置插补参数

- **插补点数**：轨迹上生成的点位数量（2-1000）
- **时间间隔**：相邻两点之间的时间间隔（秒）
- **姿态插值**：是否对Rx,Ry,Rz进行插值

### 5. 生成轨迹

点击【⚙ 生成轨迹】按钮：
- 会在表格中显示所有生成的点位
- 在3D视图中显示轨迹预览（绿色线条）
- 显示轨迹统计信息（距离、时间等）

### 6. 保存CSV

点击【💾 保存CSV】按钮，选择保存路径：
- 默认保存到 `csv/linear_trajectory_generated.csv`
- 文件包含：x, y, z, rx, ry, rz, 时间戳(秒)

### 7. 执行轨迹

生成的轨迹可以直接在"视觉引导"标签页中执行：
1. 生成的轨迹会自动加载到系统中
2. 切换到"视觉引导"标签页
3. 点击【执行轨迹】或【UDP执行】按钮

## CSV文件格式

生成的CSV文件格式示例：
```csv
x,y,z,rx,ry,rz,时间戳(秒)
300.0,0.0,200.0,180.0,0.0,0.0,0.0
312.5,0.0,200.0,180.0,0.0,0.0,0.01
325.0,0.0,200.0,180.0,0.0,0.0,0.02
...
```

## 注意事项

1. **坐标系**：所有坐标都基于机器人基坐标系（单位：mm，角度：度）
2. **姿态插值**：如果起点和终点姿态差异较大，建议开启姿态插值
3. **时间间隔**：根据机器人性能选择合适的频率（通常10-100Hz）
4. **预览功能**：生成轨迹后可以在3D视图中直观查看路径

## 示例

### 示例1：X方向直线运动50mm
- 起点：(300, 0, 200, 180, 0, 0)
- 终点：(350, 0, 200, 180, 0, 0)
- 插补点数：50
- 时间间隔：0.01s

### 示例2：斜向运动（XYZ同时变化）
- 起点：(300, 0, 200, 180, 0, 0)
- 终点：(350, 50, 250, 180, 0, 90)
- 插补点数：100
- 时间间隔：0.01s
- 姿态插值：开启
